> **Engineering Journal** is an editorial technical blog and case study repository exploring network simulation algorithms, procedural Web Audio DSP synthesis, IoT access control firmware, and client-side database sandboxing.

---

## ✨ Features

- **📖 Technical Deep-Dives**: Detailed architectural dissections of production systems and algorithms.
- **⚡ Minimalist Editorial UI**: Refined typography, tight tracking, zero AI-slop glows, clean high-density layout.
- **🔍 Instant Search & Topic Filtering**: Filter by Systems, Web Audio, IoT & Hardware, and Algorithms.
- **📱 Responsive Reader Mode**: Reading time estimations, copyable code snippets, and structured article metadata.

# Install dependencies
npm install

# Run Vite development server
npm run dev
